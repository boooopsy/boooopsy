        ✧   .  *  .  ✧       A SERVERLESS FLAT-FILE JOURNAL      ✧  .  *  .  ✧

Welcome to The Daily Thread. This project reimagines the modern blogging experience by entirely eliminating traditional backend middleware.  Instead of deploying heavy content management systems or maintaining database connection pools, this platform relies entirely on the client-side browser. It utilizes the GitHub REST API as a flat-file database for content and images, paired with Supabase to handle serverless interactions. It is decentralized, lighting-fast, and infinitely scalable.  ✨ The PhilosophyWriting should be frictionless. This architecture ensures that the writing experience perfectly mirrors the reading experience. There are no bloated dashboards or complex routing layers—just a pure, beautiful timeline of thoughts, updates, and logs.  🚀 Current FeaturesZero-Backend Flat-File System: Content is dynamically fetched and parsed directly from JSON files hosted entirely on GitHub.  In-Browser WYSIWYG Editor: Write, apply formatting (bold, quotes, code blocks), and seamlessly upload auto-optimized images directly into the repository without leaving the page.  Frictionless Engagement: Anonymous, infinite "Heart" clicking powered by a lightweight Supabase edge table.  Adaptive Viewing: Seamlessly switch between a full-bleed Expanded visual feed and a highly condensed, clamped List View.  Dynamic Timeline: A sticky, responsive chronological sidebar that tracks your reading progress and handles navigation with mathematical rubber-band easing.  Native Dark Mode: A sleek, fully integrated dark theme toggle for late-night reading and aesthetic preference.  🗺️ The Roadmap (Upcoming Integrations)The architecture is deliberately modular and built to expand. The following integrations are actively in development:Direct X (Twitter) Integration: Seamlessly cross-post timeline updates to X at the exact moment a post is baked into the repository, ensuring your audience is notified instantly.WhatsApp Publishing Pipeline: Hooking into webhook endpoints to allow publishing new logs directly via a WhatsApp chat interface, making on-the-go journaling completely native and app-free.🛠️ Architecture & Tech StackThis project strictly adheres to a minimalist, dependency-free frontend approach:Markup & Styling: Vanilla HTML5 and CSS3, heavily utilizing modern CSS Variables, Flexbox grids, and clamped element queries.  Logic & State: Vanilla JavaScript (ES6+) with progressive async/await fetching and DOM manipulation.  Storage Layer: GitHub Repository, functioning simultaneously as the flat-file JSON system and the image host.  Interaction Layer: Supabase, handling unauthenticated real-time engagement counters effortlessly.
